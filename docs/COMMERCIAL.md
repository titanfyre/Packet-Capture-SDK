# Integration offer

Start with a paid, scoped pilot on the customer's intended Windows build and adapter. Agree measurable acceptance criteria for packet integrity, teardown, coexistence, expected workload and deployment before offering production redistribution. Contact **titancsa on Discord** for evaluation access, OEM terms and maintenance.

The public application/SDK/installer source is MIT licensed. Private kernel binaries require separate evaluation/production terms. Product-specific keys and signed one-hour handle permissions provide central control over future grants, without machine fingerprints or automatic billing. Revocation does not instantly cancel a permission already accepted by the kernel. There is no guarantee against key sharing, relaying or a compromised administrator/kernel.

There is an established OEM market: [Npcap OEM](https://npcap.com/oem/redist) sells redistribution, deployment convenience and support. [WinDivert](https://reqrypt.org/windivert.html) is an existing LGPL alternative, and Windows Packet Monitor is supplied with Windows. These are competitors and alternatives, not evidence that this project has equivalent maturity, compatibility, performance or expected revenue.

The offer is an explicit integration API, qualified configurations, support and redistribution terms. Microsoft signing alone is not a product endorsement, WHQL certification, a security guarantee or a reason to add kernel code where an inbox/user-mode solution suffices. No payment processing, per-machine seat enforcement or guaranteed sales are implemented.
